# Induwara Anupriya — Developer Portfolio

Personal developer portfolio for **Induwara Anupriya**, Software Engineering Student and Aspiring Software Developer. Built with React.js, React-Bootstrap, and CSS3.

## 🚀 Overview

This modern, responsive developer portfolio highlights academic background, technical skills, verified certifications, full-stack software projects, curriculum vitae, and professional contact channels.

### Key Sections
- **Home / Hero**: Greeting, headline, professional summary, profile avatar, and primary action buttons.
- **About**: Natural background introduction, educational qualifications, and career goals.
- **Skills**: Structured competencies across Programming Languages, Web Development, Databases, Tools & Technologies, and Cloud & Operating Systems.
- **Projects**: Real-world projects including *LibraryHub* (Digital Library Management System) and *User Management CRUD System*.
- **Certifications**: Verified credentials in AWS Cloud (Foundations & Architecting), Linux (The Linux Foundation), Docker (Simplilearn), and Python (University of Moratuwa).
- **Curriculum Vitae (Resume)**: Direct PDF viewer and download capability for `Induwara_Anupriya.pdf`.
- **Contact**: Reach out via Email, LinkedIn, Phone, or the interactive contact form.

## 🛠️ Built With

- **Frontend Framework**: [React.js](https://reactjs.org/) (v17)
- **Styling**: [React-Bootstrap](https://react-bootstrap.github.io/) & Custom CSS3
- **Icons**: [React Icons](https://react-icons.github.io/react-icons/)
- **Visual Effects**: [react-tsparticles](https://particles.js.org/), [typewriter-effect](https://github.com/tameemsafi/typewriterjs), [react-parallax-tilt](https://github.com/mkosir/react-parallax-tilt)
- **Document Viewing**: [react-pdf](https://github.com/wojtekmaj/react-pdf)
- **Routing**: [React Router](https://reactrouter.com/) (v6)
